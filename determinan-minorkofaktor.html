Deret Geometri Tak Hingga

Guru: [Indah Permatasari, S.Si., M.Pd.]

[SMAN 4 Takalar]

1. Mengingat Kembali

Deret geometri adalah jumlah suku-suku barisan geometri dengan rasio tetap r = U2 / U1 = U3 / U2 = …. Jumlah n suku pertamanya:

Sn = a(1 − rn)1 − r, r ≠ 1

Pada deret tak hingga, suku dijumlahkan terus tanpa berhenti. Pertanyaannya: apakah jumlahnya bisa berupa bilangan tertentu?

2. Konvergen dan Divergen

  • Konvergen: jumlahnya mendekati satu nilai tertentu. Syaratnya |r| < 1 atau −1 < r < 1 (r ≠ 0).
  • Divergen: jumlahnya terus membesar/berayun, tidak menuju satu nilai. Terjadi jika |r| ≥ 1.

Alasannya: jika |r| < 1 maka rn → 0 saat n makin besar, sehingga Sn → a(1 − 0)/(1 − r).

S∞ = a1 − r, dengan −1 < r < 1

3. Simulasi Interaktif

Geser nilai a dan r. Batang menunjukkan jumlah n suku pertama (Sn), garis merah putus-putus adalah S∞ (jika ada).

a = 8 r = 0.5

4. Penerapan

a) Pecahan desimal berulang. 0,555… = 0,5 + 0,05 + 0,005 + … → a = 0,5; r = 0,1 → S = 0,5 / 0,9 = 5/9.

b) Bola memantul. Bola dijatuhkan dari tinggi h, memantul setinggi r kali tinggi sebelumnya. Panjang lintasan total:

L = h + 2 · h · r1 − r

c) Suku ganjil / genap. Jumlah suku-suku ganjil adalah deret baru dengan suku pertama a dan rasio r2: Sganjil = a / (1 − r2).

Contoh Soal Berlangkah

Coba kerjakan sendiri dulu, lalu klik untuk melihat pembahasan.

Contoh 1 (Dasar): Hitung 18 + 6 + 2 + …

Rasio r = 6/18 = 1/3. Karena |1/3| < 1, deret konvergen.
S∞ = a/(1 − r) = 18 / (1 − 1/3) = 18 / (2/3) = 27.

Contoh 2 (Menengah): Ubah 0,2727… menjadi pecahan

0,2727… = 0,27 + 0,0027 + 0,000027 + … → a = 0,27; r = 0,01.
S = 0,27 / (1 − 0,01) = 0,27/0,99 = 27/99 = 3/11.

Contoh 3 (Menengah): Tentukan x agar 1 + (x − 2) + (x − 2)² + … konvergen

Rasio r = x − 2. Syarat: −1 < x − 2 < 1 → 1 < x < 3.
Untuk x = 2,5 diperoleh r = 0,5 sehingga S = 1/(1 − 0,5) = 2.

Contoh 4 (Tingkat lanjut): Suku pertama dan jumlah tak hingga

Jumlah tak hingga 12 dan U2 = 3. Tentukan a.
U2 = ar = 3 dan a/(1 − r) = 12 → a = 12(1 − r).
Substitusi: 12(1 − r)r = 3 → r − r² = 1/4 → (r − 1/2)² = 0 → r = 1/2.
Maka a = 12(1/2) = 6.

Contoh 5 (Tingkat lanjut): Bola memantul

Bola dijatuhkan dari 16 m dan memantul 3/4 kali tinggi sebelumnya. Panjang lintasan total?
Tinggi pantulan: 12, 9, … → a = 12, r = 3/4 → jumlah = 12/(1/4) = 48.
Lintasan = 16 + 2(48) = 112 m.
