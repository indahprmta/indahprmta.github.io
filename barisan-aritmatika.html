Diketahui barisan 3, 7, 11, 15, ... Beda (b) dari barisan tersebut adalah?

3, 7, 11, 15, ...
Petunjuk Tingkat: Mudah
Pembahasan & Jawaban Solusi Detail
Jawaban Akhir b = 4

Langkah-langkah:

• Suku pertama (a) = 3

• Beda (b) = U₂ - U₁

• b = 7 - 3 = 4

Ringkasan Rumus Barisan Aritmetika

1. Suku ke-n (Un)
Un = a + (n - 1)b

a = suku pertama (U₁)
b = beda / selisih (Un - Un-1)
n = urutan suku yang dicari

2. Beda (b)
b = U2 - U1  atau  b = (Uk - Um) / (k - m)

Selisih konstan antara dua suku yang berurutan.

3. Banyak Suku (n) & Suku Tengah (Ut)
n = (Un - a)/b + 1  |  Ut = (a + Un)/2

Menentukan jumlah seluruh suku pada barisan terbatas dan nilai suku tengahnya.
