Concept Study

What is a Geometric Translation?

A translation slides a geometric figure (pre-image) a certain distance in a specific direction without changing its size, shape, or orientation. Think of it as pushing an object on a flat table!

The Translation Vector

Translation is defined by a vector representing horizontal displacement $a$ (along the x-axis) and vertical displacement $b$ (along the y-axis).

$$T = \begin{pmatrix} a \\ b \end{pmatrix}$$

The General Formula

To find the coordinates of an image point $P'(x', y')$ translated by $T(a,b)$ from the pre-image $P(x,y)$, we simply add the translation components:

$$x' = x + a \quad \text{and} \quad y' = y + b$$ $$P(x,y) \xrightarrow{T\begin{pmatrix}a\\b\end{pmatrix}} P'(x+a, y+b)$$

Key Properties

  • Isometry: Distance is preserved; sizes of shapes stay identical.
  • Orientation: Vertices remain in the same relative clockwise/counter-clockwise order.
  • Parallelism: Parallel lines in the pre-image remain parallel in the image.
Visual Guide

Understanding Directions of $a$ and $b$

The direction of translation depends entirely on the sign of the translation components inside vector $\begin{pmatrix} a \\ b \end{pmatrix}$:

a > 0 Moves the shape to the Right
a < 0 Moves the shape to the Left
b > 0 Moves the shape Up
b < 0 Moves the shape Down

Guided Problem Solving

Step-by-Step Examples

Walk through these solved geometric translation problems to master various scenario-based techniques.

Example 1: Basic Point Translation Standard Level

Translate point $A(-4, 2)$ using the translation vector $T = \begin{pmatrix} 6 \\ -5 \end{pmatrix}$. Find the coordinates of the image point $A'$.

Solution Walkthrough:

  1. Identify variables in translation formula: $x = -4$, $y = 2$, $a = 6$, $b = -5$.
  2. Apply general translation rule: $P(x, y) \rightarrow P'(x+a, y+b)$.
  3. Substitute coordinates:
    $A'(-4 + 6, \, 2 + (-5))$
  4. Simplify simple mathematical operations:
    $A'(2, \, -3)$
Final Answer
A' (2, -3)
Point shifted 6 units right and 5 units down.
Example 2: Finding Original Point (Pre-image) Medium Level

Under a translation $T = \begin{pmatrix} -3 \\ 4 \end{pmatrix}$, the image of point $B$ is $B'(1, -2)$. Find the coordinates of point $B$.

Solution Walkthrough:

  1. Given quantities: translated point $B'(1, -2)$, and vector values $a = -3$, $b = 4$. We need to find $B(x, y)$.
  2. Write the system equations:
    $x + a = x' \implies x + (-3) = 1$
    $y + b = y' \implies y + 4 = -2$
  3. Solve each independent equation for $x$ and $y$:
    $x = 1 - (-3) = 1 + 3 = 4$
    $y = -2 - 4 = -6$
Final Answer
B (4, -6)
To reverse translation, we subtract vector components from image coordinates.
Example 3: Translating an Equation of a Line Hard Level

Find the equation of the line $y = 3x - 1$ after it is translated by $T = \begin{pmatrix} 2 \\ -4 \end{pmatrix}$.

Solution Walkthrough:

  1. Represent the translation of general point coordinate variables:
    $x' = x + 2 \implies x = x' - 2$
    $y' = y - 4 \implies y = y' + 4$
  2. Substitute these new expressions into our original linear line equation:
    $(y' + 4) = 3(x' - 2) - 1$
  3. Expand linear products and simplify constants algebraically:
    $y' + 4 = 3x' - 6 - 1$
    $y' + 4 = 3x' - 7$
    $y' = 3x' - 7 - 4 \implies y' = 3x' - 11$
Final Answer
y = 3x - 11
The line shifts 2 units right and 4 units down, remaining parallel to the original.
